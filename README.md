# SWYNEX-Nike-Sales-EDA
# Nike Sales Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of a Nike sales dataset as part of my data analytics task with SWYNEX Technologies.

The objective is to explore sales and profitability patterns, compare product lines and regions, and identify useful business insights using Python and SQL.

## Objectives

* Explore and understand the Nike sales dataset.
* Analyze profit across different product lines.
* Compare profitability across regions.
* Investigate sales performance across sales channels.
* Identify patterns and potential business opportunities.
* Present findings through queries, visualizations, and analysis.

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* MySQL
* SQL
* Microsoft Excel
* Google Colab
* GitHub

## Dataset

The project uses a cleaned Nike sales dataset containing information about products, regions, sales channels, revenue, discounts, order dates, and profit.

Important columns include:

* Order_ID
* Product_Line
* Product_Name
* Gender_Category
* Size
* Units_Sold
* MRP
* Discount_Applied
* Revenue
* Order_Date
* Sales_Channel
* Region
* Profit

## SQL Analysis

SQL was used to summarize and compare recorded profit across different categories.

Analyses include:

1. Total profit by product line.
2. Total profit by region.
3. Total profit by sales channel.
4. Total profit by product name.

## Key Findings

### Regional Profitability

* Bengaluru recorded the highest total profit, at approximately 621,948.74.
* Kolkata ranked second, at approximately 602,856.74.
* Delhi ranked third, at approximately 587,148.93.
* Hyderabad recorded the lowest total profit, at approximately 525,094.60.
* The difference between Bengaluru and Hyderabad was approximately 96,854.14.

### Product-Line Profitability

The product-line analysis compares total recorded profit across Nike product lines to identify the strongest-performing categories.

## Data Quality Considerations

The dataset contains missing values in some fields, including revenue, order dates, and units sold. These limitations should be considered when interpreting the results. Further data quality checks are needed before drawing conclusions from analyses that depend on these columns.

## Conclusion

This project demonstrates the use of SQL and Python to explore sales data, compare profitability across business categories, and communicate findings through data analysis.

Further analysis of sales volume, revenue, and discounts can help investigate the factors contributing to differences in profitability.
